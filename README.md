# Point of Sale — schema-first

A point-of-sale sample built schema-first: the database was designed first, then the Entity Framework
model was generated from it. Written in 2017 while learning ASP.NET MVC.

**Built with:** C# · ASP.NET MVC · Entity Framework · SQL Server

**Running it:** open the solution in Visual Studio, repoint the connection string in `Web.config`,
and run.

**Status:** archived. A 2017 learning project, kept for reference and not maintained.
